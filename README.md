# car_service_management_system
проект направлен на создание системы управления автосервисом для автоматизации повседневных задач бизнеса. Основан на технологиях C#, WPF и PostgreSQL. Будет осуществлен переход от двухуровневой архитектурой (клиент-сервер) на трехуровневую архитектуру (SOA) - в учебных целях.
